A single original fortune-cookie line for a software developer: a small truth about who really inherits today's code, turned into a kind nudge to write the comment. It reads like a real fortune slipped into a cookie at the end of a long day — the reader is the future debugger, so be kind to them. Running `main.py` writes that one line to `entry.txt` — first to the grader's output directory, then as a local copy. Pure Python standard library, no network, no dependencies.

## Run it

```sh
python3 main.py
```
